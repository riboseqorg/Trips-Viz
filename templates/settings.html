General settings

Background colour
This sets the background colour for almost all plots on Trips-viz.
Title Size
This controls the size of the plot titles
Subheading Size
This controls the size of the subheadings, where transcript id and length are displayed
Axis Label Size
This controls the size of the axis labels
Tick Marker Size
This controls the size of the numbers on the x and y axis
Legend Size
This controls the size of the labels on plots with interactive legends
CDS Markers Width
This controls the width of the CDS markers on the single transcript and comparison plots
CDS Markers Colour
This controls the colour of the CDS markers on the single transcript and comparison plots

Single gene/transcript plot

UAG Colour
This sets the colour of the UAG stop codons in the open reading frame architecture.
UAA Colour
This sets the colour of the UAA stop codons in the open reading frame architecture.
UGA Colour
This sets the colour of the UGA stop codons in the open reading frame architecture.
Riboseq line width
This controls the width of the red, green and blue ribo-seq lines.

Single gene/transcript comparison plot

UAG Colour
This sets the colour of the UAG stop codons in the open reading frame architecture.
UAA Colour
This sets the colour of the UAA stop codons in the open reading frame architecture.
UGA Colour
This sets the colour of the UGA stop codons in the open reading frame architecture.

Metainformation settings

Readlength distribution bar colour
This sets the colour of the bars in the read length distribution plot.
Metagene fiveprime bar colour
This sets the colour of the bars in the metagene profiles for the fiveprime ends.
Metagene threeprime bar colour
This sets the colour of the bars in the metagene profiles for the threeprime ends.
Nucleotide composition A colour
This sets the colour of the line for the A nucleotide in the nucleotide composition plots.
Nucleotide composition T colour
This sets the colour of the line for the T nucleotide in the nucleotide composition plots.
Nucleotide composition G colour
This sets the colour of the line for the G nucleotide in the nucleotide composition plots.
Nucleotide composition C colour
This sets the colour of the line for the C nucleotide in the nucleotide composition plots.
